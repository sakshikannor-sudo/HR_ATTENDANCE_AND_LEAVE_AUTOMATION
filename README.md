# 🤖 HR Attendance & Leave Automation

**Python + Excel + n8n based HR automation project**

### ✨ Features
- 📊 Attendance & Leave Analysis
- 🏖️ 3-Leave Monthly Policy
- 🚨 4th Leave Emergency Approval
- 📧 Automated Email Notifications
- ⚡ n8n Workflow Automation
- 📑 Excel & Google Sheets Integration
